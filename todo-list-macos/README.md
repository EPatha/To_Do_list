# To-Do List Application for macOS

## Overview
This is a To-Do List application designed for macOS that allows users to manage their tasks efficiently. The application includes unique features such as notifications, voice input, and text input for adding tasks.

## Features
- **Task Management**: Create, update, and delete tasks.
- **Notifications**: Schedule reminders for tasks.
- **Voice Input**: Add tasks using voice commands.
- **User Interface**: Intuitive UI for managing tasks.

## Project Structure
- `src/main`: Contains the main application files.
- `src/models`: Contains the data models for the application.
- `src/views`: Contains the UI components for displaying tasks.
- `src/controllers`: Contains the logic for managing tasks.
- `src/utils`: Contains utility classes for notifications and voice input.
- `tests`: Contains unit tests for the application.
- `Package.swift`: Configuration for Swift Package Manager.

## Installation
1. Clone the repository.
2. Open the project in Xcode.
3. Build and run the application.
